# 开发指南

## 本地开发

项目采用 Manifest V3，无构建步骤、无运行时依赖，仅申请 `storage` 权限。内容脚本限定在 DeepSeek、Gemini、ChatGPT、豆包、千问（qianwen.com）和 Kimi 六个指定网站运行。

安装 Node.js 18+ 后，在仓库根目录执行：

```sh
npm install
npm test
npm run check
```

在浏览器扩展管理页加载仓库根目录。修改内容脚本或清单后，需要重新加载扩展，再刷新聊天网页。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `src/catalog.js` | 40 个规范 emoji 的语义及图片映射，另支持 `😄`、`🙂` 两个别名 |
| `src/sizing.js` | 原字形尺寸、字体缓存及行距调整 |
| `src/engine.js` | 站点正文选择器、字形高亮与图片覆盖 |
| `src/content.js` | 页面变化监听、渲染生命周期及设置更新 |
| `popup/` | 扩展开关、尺寸选择、预览及自动保存 |

## 渲染约定

- 不修改、拆分或移动宿主 Text 节点。通过 CSS Custom Highlight 隐去对应字形，在原位置覆盖图片，保持追加、整段覆写和文本选择的原始内容。不支持高亮 API 时保留原 emoji。
- 覆盖图挂在同一滚动边界内已有的定位容器，随正文自然滚动，不通过滚动事件逐帧追赶。找不到安全容器时保留原 emoji，不修改宿主定位样式。
- 使用本机 emoji 字体为 24–64px 图片预留字形宽度，并调整行距；普通文字字号不变。关闭后恢复原排版。
- 本机字体或字体缩放 API 不可用时回退到原占位。未收录组合与已收录表情共享码点时，相关码点保留原字体，避免破坏组合字形。
- 图片未就绪或加载失败时保留原 emoji。素材缓存由同一文档的回复共享。
- 普通流式更新仅处理受影响回复；共享布局变化才触发全局重定位。字体加载完成后重新定位。
- 设置保存在 `chrome.storage.local`，设置页连续操作串行写入，并保留最新待保存值。扩展不保存聊天内容。

添加新站点时，先在真实页面核对消息角色和正文区域，再增加清单匹配与回归测试。不要使用全页面兜底选择器。`web_accessible_resources.matches` 的路径必须为 `/*`，与内容脚本的路径限制分别校验。

## 验证

自动测试覆盖流式覆写和追加、宿主重绘、历史回复、角色变化、关闭恢复、代码保护、组合 emoji、字体生命周期和设置保存顺序。DOM 测试显式模拟布局与高亮 API，不能替代浏览器绘制验证。

流式追加回归：

```sh
node scripts/reproduce-stream-append.mjs
```

浏览器回归：

```sh
python3 -m http.server 4187 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4187/tests/visual.html`。该页面加载生产脚本并模拟设置接口，可检查：

- 24–64px 共 11 档图片与原字形占位的实际尺寸。
- 追加、覆写、开关恢复和文本选择。
- 窄窗口换行及滚动定位；同步滚动按钮在同一次操作内比较文字与图片的位移。

千问仅匹配回答卡片中的正文，Kimi 仅匹配助手最终正文并排除思考及工具容器。DOM 回归覆盖六站的流式更新、历史回复和正文保护。维护站点适配时，还应在真实页面检查多表情、换行、滚动、尺寸切换、复制行为及不同系统字体；DOM 测试不能代替实站绘制验收。

## 已知限制

若响应式样式仅改变字体族或行高、字号不变，窗口重定位可能保留旧排版，直到正文更新或设置刷新。已在 Chrome 最小页面复现，尚未确认支持站点存在相同触发规则；当前作为后续兼容性改进保留。`body` 或回复祖先的类名变化已有强制重算，不属于相同路径。

网页结构改版可能导致匹配失效，此时应保留原内容。图片来源及权利边界见 [素材说明](../ASSETS.md)。
