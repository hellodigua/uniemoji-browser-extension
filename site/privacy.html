PRIVACY POLICY

隐私政策

更新日期：2026 年 11 月 16 日

UniEmoji 在你的浏览器内，把 AI 回复中的 emoji 显示为对应表情。聊天内容不上传给我们，也不用于广告、分析或模型训练。

我们处理哪些内容

扩展在支持的 DeepSeek、Gemini、ChatGPT、豆包、千问和 Kimi 网页上，读取 AI 回复正文中的文字并识别已收录的 emoji，以在原位置显示表情图片。相关处理在当前浏览器页面内完成，不持久保存聊天记录，不向开发者或其他第三方传输聊天内容。扩展不主动读取账号密码、Cookie 或浏览历史。

本地保存的设置

扩展使用 chrome.storage.local 保存是否启用替换和表情尺寸。这些设置只保存在当前浏览器的本地扩展存储中，不通过本扩展上传或同步到服务器。当前版本的表情图片随扩展提供，显示时无需从外部服务器下载。

权限为什么必要

storage 权限用于记住你的设置。在上述支持网站运行内容脚本，是为了识别 AI 回复中的 emoji 并调整其显示；扩展无需在其他网站读取内容。

数据用途与共享

网页内容仅用于用户可见的表情替换功能。我们不出售或共享聊天数据，不投放广告，不嵌入统计分析或追踪代码，也不将聊天数据用于模型训练。UniEmoji 对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。

你的控制方式

你可以在扩展弹窗中关闭表情替换，或在浏览器扩展管理页面禁用、卸载扩展。卸载会移除扩展的本地设置。网页上的原有聊天记录仍由对应聊天平台管理，不受本扩展的卸载影响。

本网站与外部链接

本网站不设置分析或广告 Cookie，不包含第三方统计脚本。网站通过 GitHub Pages 托管，托管服务可能出于提供服务和安全的目的处理访问日志（例如 IP 地址），详情见 GitHub 隐私声明。访问聊天平台或 GitHub 等外部网站时，适用相应网站的隐私政策。

联系与更新

本扩展由 GitHub 用户 hellodigua 维护。如有隐私问题，请通过 GitHub Issues 联系。Issues 为公开页面，请勿提交私人聊天内容、账号凭据等敏感信息。数据处理方式如有变化，我们会同步更新本页面及更新日期。
